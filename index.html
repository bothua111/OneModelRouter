01

是什么，能做什么

一个跑在你自己电脑上的本地网关：把零散的免费模型通道统一管理，对外只暴露一个 OpenAI 兼容地址，任何支持自定义 API 的 AI 工具都能直接接入。

F.01

统一网关

OpenAI 兼容 /v1 接口，一个地址接入所有模型，兼容各类 Agent 与客户端。

F.02

免费渠道聚合

20+ 免费 / 额度通道集中管理，可视化 Web 面板勾选启用，无需逐家配置。

F.03

模型组轮询

多个模型组成一组自动切换，故障、限流自动转移，调用不中断。

F.04

多账号池

渠道内多账号轮换，凭据过期自动续期，失败自动换号重试。

F.05

自动签到

每日自动领取各渠道积分 / Token 额度，无需手动逐个打卡。

F.06

本地运行

数据留在自己电脑，隐私可控；管理面板 127.0.0.1:18681。

03

重要提示

请先读完再使用
  • 转发渠道务必用小号 / 备用账号，避免主账号被平台风控，切勿用常用主力账号。
  • 控制调用频率，不要高频、批量或商业化滥用，正常使用节奏即可。
  • 各渠道免费额度随时可能调整或失效，是否可用以官方为准，本工具不保证长期稳定。
  • 本工具不破解、不绕过付费，仅聚合各平台公开提供的免费入口。
